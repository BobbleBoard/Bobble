The Bobble mark: three tiles on a two-by-two board with the top-left cell empty.

Use the Logos assets as they are: `bobble-mark-ink.svg` on light grounds, `bobble-mark-white.svg` on dark, `app-icon.svg` where the app itself is meant. Inline, `.bb-mark` draws it in `mark-ink`. Keep one tile's width clear on every side. The mark in its three hues (`bobble-mark-hues.svg`, `.bb-mark--hues`) is for the cover and the about page only.

- Do not recolour a single tile, fill the empty cell, rotate the board or add a frame.
