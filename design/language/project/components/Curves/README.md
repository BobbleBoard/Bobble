The seven curves of the language, one per verb, each shown doing its verb.

Arrive on `ease-settle`, glide the cursor on `ease-glide` (`duration-travel`), slide a tile on `ease-slide`, place a mark on `ease-bob`, change colour on `ease-standard`, leave on `ease-exit`. `ease-press` is for a control's press and release. Pick the curve by the verb, not by taste.
