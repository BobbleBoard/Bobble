The three hues from the mark, each with one job, so a picture's colour tells you what kind of thing it is.

Teal is words and numbers, sun is pictures and pages, pink is things that move. Each has a tint (washes) and an ink (text in that colour). Choose one per picture with `.bb-hue-teal`, `.bb-hue-sun` or `.bb-hue-pink` on the scene.
