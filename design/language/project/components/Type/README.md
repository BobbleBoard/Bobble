Fraunces, softened, names things; the system face does everything else.

Display classes (`display-xl` to `display-s`) and `.bb-title` are Fraunces with `SOFT 100` and `WONK 0`, set by `bundle.css`. Interface classes (`title`, `heading`, `prose`, `body`, `label`, `caption`, `eyebrow`) are the system face, `code` is the mono face. Never set body copy in Fraunces, or Fraunces below 20px.
