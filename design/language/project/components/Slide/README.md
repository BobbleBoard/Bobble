The mark's own motion: a sliding-tile puzzle that never breaks its rule.

Add `.bb-mark--slide` to an inline mark whose tiles carry `t1` (top right), `t2` (bottom left) and `t3` (bottom right). Only the tile beside the hole moves, into the hole, one slide per `duration-slide` beat on `ease-slide`; twelve beats bring every tile home, so the loop closes on the still mark. Use it to mean "making" (a picture being drawn, a model loading) and nowhere else.
