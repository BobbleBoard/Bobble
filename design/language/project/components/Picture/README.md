What a made image looks like inside a picture: a plate in the hue's tint with two hills and a sun.

`.bb-picture` is the plate (16:10 by default); inside, an SVG with `.hill`, `.hill-back` and `.sun`. The hills are tiles turned 45°, so the plate is built from the same unit as everything else. In dark the sun takes the hue. While an image is being made, the plate holds the mark's sliding puzzle (`.bb-mark--slide`) instead.

- Use sun for pictures and pages; pink for a still from a video.
