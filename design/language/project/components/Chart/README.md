Numbers in a picture: bars standing on a baseline, or a line through nodes.

`.bb-bars` holds `.bb-bar` elements with `--h` (a percentage) and `--bw` (bar width); `--quiet` draws a bar as an outline. A bar has tile corners on top and is square at the foot. `.bb-spark` is an SVG with `.rule`, `.path` (3.5 wide) and `.node`. Put nodes only where the story is: the peak, the latest value.

- Charts are teal, the hue for words and numbers.
