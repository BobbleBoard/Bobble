The glass pill that offers one action on what is selected, or confirms it was done.

`.bb-chip` is `overlay` glass with an `edge` ring and `shadow-popover`, 32 high, `label` text, an optional 15px icon from the set first. Place it below the selection, never over it. Two jobs only: offer ("Edit with Bobble") and confirm ("Added to Calendar"). What the agent is doing right now is shown by its cursor's pill, not a chip.
