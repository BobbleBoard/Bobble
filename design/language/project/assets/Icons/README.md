The app's icons, rendered from packages/ui (icons.tsx and glyph.tsx), one Hugeicons family (MIT; see Licenses), stroke only, ink `#1D1D1F`.

- `glyph-*.svg`: places and tools, the sidebar's and the studios' own drawings.
- `icon-*.svg`: controls, plus the app-local set (play, pause, warning, sun, moon, key and the rest). Where an idea is also a glyph, the icon is that glyph.

Each is 16px with a 24 viewBox and stroke 1.5, which draws 1px at 16px: the app's `--pd-icon-stroke` and the stem of 13px text. Inline them with `class="bb-icon"` to take the text colour; as files they are ink-only. No brand marks are here (the app's GitHub icon is GitHub's own mark, from simple-icons): a connector's icon is its official mark, copied separately.
